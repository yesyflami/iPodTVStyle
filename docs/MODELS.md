# 机型清单

> **这份清单来自 [CleanYourTV · examples](https://github.com/Gathin23/cleanyourtv/blob/main/examples/README.md)（MIT）**，
> 共 **457** 个机型 / 品牌，每个机型都对应上游一个 `examples/<机型>/` 目录（记录该固件上哪些预装可以安全禁用）。
>
> iPodTVStyle 复用的是同一套思路 —— 装一个声明了 `HOME` 的 app，再让系统选它 —— 所以**能不能换桌面，
> 取决于这台机器的固件愿不愿意交出 HOME 角色**。上游清单主要是记录"能删什么"，不是"能换桌面"，
> 因此下面把 457 个机型按备注里的线索分了三档：**✅ 已实测可换 · ❌ 明确不可换 · ⚠️ 未验证**。
>
> 你手上有机器并实测通过？欢迎提 PR 把状态改成 ✅。

## 怎么用

1. 先在表里搜你的电视型号（`Ctrl/⌘ + F`）
2. 状态是 **✅** → 直接按 [ADAPT.md](ADAPT.md) 装
3. 状态是 **❌** → 这台机器的固件锁了 HOME，装不进去，别浪费时间
4. 状态是 **⚠️** → 清单没提这事，用下面三条命令自己验：

```bash
# 1 · 系统版本够不够（要 Android 8.0+）
adb shell getprop ro.build.version.release

# 2 · 是不是 Android TV / Google TV（有 leanback 才算）
adb shell pm list features | grep -i leanback

# 3 · 系统现在认哪个桌面？能不能被顶替？
adb shell cmd package resolve-activity -c android.intent.category.HOME
```

第 3 条如果能正常输出 `packageName=...`，基本就有戏；如果直接报错、或者装完按 HOME 没反应，
就是固件层面的限制。

## 说明

- **"❌ 不可换"的判断依据**：上游备注里明确写了固件锁定（Home 键写死、保留原桌面、拒绝第三方桌面、
  HOME 声明触发签名校验等）。这些机型仍可以只做去广告，只是换不了桌面。
- **"⚠️ 未验证"不是"不能"**：上游作者只做了去广告，没在这台机器上试过换桌面。很多这类机型的固件
  其实可以（作者自己那台创维 7S77 就属于这一类），所以值得花两分钟用上面的命令试一次。
- **清单会过时**：固件 OTA 之后 HOME 策略可能变。上游清单更新时，这份文件也应该同步。
- 商标与机型信息归各厂商所有，这里仅用于兼容性说明。
