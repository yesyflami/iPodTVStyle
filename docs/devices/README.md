# 逐机型记录

一个机型一个文件，只写**这台机器上实测过的事实**。目的很具体：下一个人拿到同型号的电视时，
不用再重新试一遍"它认不认第三方桌面、认哪个包名、Home 键走哪条路"。

没有记录的机型不代表不能装 —— 直接跑 `tools/install.sh`，它会自己问电视。
记录只是把已经踩过的坑写下来。

## 什么时候需要新建一个文件

- 这台机器**需要白名单包名**才能拿到 HOME（`install.sh` 报 HOME 没落到新桌面，但安装成功）；
- 这台机器的 **Home 键 / 开机路径不走 Android 的 HOME 偏好**（见 [ADAPT.md §5](../ADAPT.md)）；
- 装的时候电视弹了特殊的确认框，或者 adb 有特殊开关位置；
- 有已知会让机器卡死/半砖的包（**不要**只写"别动"，要写清楚现象和恢复命令）。

## 模板

```markdown
# 品牌 型号（区域，Android 版本）

| 字段 | 值 |
|---|---|
| 型号 / 主板 | 例：Skyworth 7S77_A6M / sky848_9s60 |
| Android / SDK | 例：8.0 / 26 |
| 物理分辨率 / UI | 例：1920×1080 / 1920×1080，240 dpi |
| HOME 现状 | 谁拥有 HOME（install.sh 打印的那一行） |
| 是否需要白名单包名 | 不需要 / 需要：`<package>` |
| Home 键是否走 Android 偏好 | 是 / 否（否的话写固件属性名或所需 helper） |
| 安装时的特殊行为 | 例：电视上会弹"继续安装"，必须用遥控器确认 |

## 结果

| 检查项 | 结果 |
|---|---|
| 安装 | 成功 / 失败（错误码） |
| HOME 交接 | `install.sh` 通过 / 未通过（原因） |
| 按 Home 键 | 回到新桌面 / 回到原厂 / 无反应 |
| 重启后 | 仍在新桌面 / 回到原厂 |
| 主题切换 | 正常 / 异常 |
